Kata Sandi Petugas

Ganti kata sandi untuk login ke dashboard ini. Username tetap admin — yang bisa diganti hanya kata sandinya. Gunakan ikon mata di kanan kolom untuk melihat sandi yang sedang diketik.

Mode demo: kata sandi tersimpan di browser perangkat ini (versi produksi: hash bcrypt di server). Simpan kata sandi baru di tempat aman — jika lupa, hapus data situs dari browser untuk kembali ke sandi bawaan. Setelah sandi diganti, petunjuk kredensial di halaman login otomatis disembunyikan.
